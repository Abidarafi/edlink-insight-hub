# EdLink Usability Insights

Repository ini berisi source code dashboard berbasis web untuk menyajikan hasil analisis kemudahan penggunaan aplikasi EdLink menggunakan metode System Usability Scale (SUS).

## Deskripsi Project

Dashboard ini dikembangkan sebagai bagian dari penelitian skripsi dengan judul:

**Perancangan Sistem Informasi Dashboard Analisis Kemudahan Penggunaan Aplikasi EdLink Menggunakan Metode System Usability Scale pada Institut Teknologi PLN**

Dashboard digunakan untuk menampilkan hasil pengolahan data kuesioner SUS dari 100 responden mahasiswa Institut Teknologi PLN. Informasi yang ditampilkan meliputi skor SUS, kategori interpretasi, distribusi skor, karakteristik responden, dan rata-rata skor kontribusi tiap item pernyataan.

## Fitur Dashboard

- Menampilkan rata-rata skor SUS.
- Menampilkan median, skor tertinggi, dan skor terendah.
- Menampilkan interpretasi skor berdasarkan Acceptability Ranges, Grade Scale, dan Adjective Rating.
- Menampilkan distribusi kategori hasil SUS.
- Menampilkan karakteristik responden berdasarkan angkatan dan jenis kelamin.
- Menampilkan rata-rata skor kontribusi tiap item pernyataan.
- Menyediakan filter data berdasarkan angkatan dan jenis kelamin.
- Menyajikan tabulasi data hasil analisis dalam bentuk visual yang lebih mudah dipahami.
